素材資料夾說明
==============
把你畫好的 PNG 放進下列任一位置，檔名要完全一致（找不到就用預設樣式）：
  1. %AppData%\InnovationEasyLauncher\Assets\   （優先，可隨時換圖，重開啟動器生效）
  2. 啟動器 exe 旁邊的 Assets\

每張圖都會「拉伸撐滿」它的位置，所以不需要先對齊尺寸；
建議比例可參考設計稿（視窗 980x640，左 311 / 中 551 / 右 117）。

  background.png            整個視窗背景（建議 1960x1280）
  logo.png                  左上角 IEML 標誌
  avatar_frame.png          頭像外框（約 132x124）
  avatar_default.png        沒有頭像時的預設圖
  btn_launch.png            啟動按鈕（約 253x83）
  btn_instance_settings.png 實例設置（約 126x93）
  btn_instance_pick.png     實例選擇（約 126x93）
  card.png                  快捷啟動卡片底圖（約 208x260）
  btn_settings.png          右欄「設置」
  btn_download.png          右欄「下載」
  btn_p2p.png               右欄「P2P」
  btn_more.png              右欄「更多」
  btn_music.png             右欄「音樂」

按鈕圖有放的話，圖上要自己畫好文字；沒放圖時會顯示預設的框與文字。
