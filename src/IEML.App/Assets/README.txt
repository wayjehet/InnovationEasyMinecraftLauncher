素材（自訂圖片）說明
====================
每個部位都可以換圖。最簡單的方法：設置頁 →「自訂圖片（素材）」按「選圖」，會立刻套用。
也可以手動放檔：把 PNG 以「部位名.png」放進下列任一位置（變更會立刻套用，不用重開）：
  1. %AppData%\InnovationEasyLauncher\Assets\   （優先）
  2. 啟動器 exe 旁邊的 Assets\

【拉伸方式】
  預設整張圖拉伸撐滿。按鈕、面板這類會變大小的部位，建議在設置頁設「九宮格邊距」（單位：圖片像素）：
  四個角維持原樣、四條邊與中間才拉伸。設定存在同資料夾的 skin.json。
  「像素風」會關閉平滑，放大時保持銳利的像素格。
【按鈕狀態】
  標示（含狀態）的部位可再放：部位名_hover.png（滑過）、部位名_pressed.png（按下）、部位名_disabled.png（停用）。沒放就沿用一般圖。
【圖上要不要畫字】
  標示「圖上要畫字」的按鈕，有放圖時程式不再畫文字與圖示，要自己畫在圖上；
  其他（一般按鈕、描邊按鈕、分頁…）文字由程式畫在圖上，圖裡不要有字。
【素材包】
  設置頁可「匯出素材包」（zip，含拉伸設定）和「匯入素材包」，方便分享。匯入只接受根目錄、檔名是下表部位名的 PNG。

部位清單（檔名＝部位名.png）：

[背景與標誌]
  background            視窗背景　建議 1960×1280，撐滿並裁掉多出的邊
  logo                  左上角標誌　高約 44，等比縮放
  avatar_frame          頭像外框　約 64×64，疊在頭像上，中間要透明

[面板]
  panel_main            主畫面外框　三欄底板（980×640），建議用九宮格
  card                  快捷啟動卡片　約 210×104
  modal                 對話框　確認、新增實例等小視窗的底板，建議九宮格
  menu                  下拉／右鍵選單　下拉清單與選單的底板

[按鈕]
  btn_primary           一般按鈕（全程式通用）　〔含狀態〕　文字由程式畫，圖上不要有字；可九宮格
  btn_ghost             描邊按鈕（全程式通用）　〔含狀態〕　文字由程式畫，圖上不要有字；可九宮格
  btn_launch            啟動鍵　〔含狀態〕〔圖上要畫字〕　約 253×83，圖上要自己畫字
  btn_instance_settings 實例設置　〔含狀態〕〔圖上要畫字〕　約 126×93，圖上要自己畫字
  btn_instance_pick     實例選擇　〔含狀態〕〔圖上要畫字〕　約 126×93，圖上要自己畫字
  btn_settings          右欄「設置」　〔含狀態〕〔圖上要畫字〕　圖上要自己畫字與圖示
  btn_download          右欄「下載」　〔含狀態〕〔圖上要畫字〕　圖上要自己畫字與圖示
  btn_p2p               右欄「P2P」　〔含狀態〕〔圖上要畫字〕　圖上要自己畫字與圖示
  btn_more              右欄「更多」　〔含狀態〕〔圖上要畫字〕　圖上要自己畫字與圖示
  btn_music             右欄「音樂」　〔含狀態〕〔圖上要畫字〕　圖上要自己畫字與圖示

[輸入與控制項]
  input                 輸入框　文字框、密碼框的底，可九宮格
  dropdown              下拉選單（收合時）　可九宮格
  tab                   分頁（未選）　可九宮格
  tab_selected          分頁（選中）　可九宮格
  progress_track        進度條軌道　可九宮格
  progress_fill         進度條填充　有放圖時不顯示光澤動畫；可九宮格

注意：舊版的 avatar_default.png 一直沒有接上畫面，已從清單移除。
圖片會轉成 PNG 存放；單張上限 20 MB、8192×8192。
